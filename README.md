# Mahtab Mode — Front-end Demo
فروشگاه مد زنانه با HTML، CSS و Vanilla JavaScript.

## اجرا
پوشه را استخراج کنید و `index.html` را باز کنید؛ پیشنهاد می‌شود از VS Code و Live Server استفاده کنید. برای فونت و تصاویر آنلاین، اینترنت لازم است.

## امکانات
- صفحات Home، Shop، Product Detail، Lookbook، About، Blog، Article، Contact، Cart Drawer، Checkout Demo و 404
- فیلتر زنده دسته‌بندی، رنگ، قیمت و موجودی؛ مرتب‌سازی
- تغییر تصویر محصول در Hover، انتخاب سریع رنگ و سایز، Quick View
- راهنمای سایز در صفحه محصول
- سبد خرید با افزایش/کاهش تعداد و حذف کالا
- Wishlist و Cart با localStorage
- ثبت سفارش دمو و نگهداری محلی اطلاعات سفارش
- طراحی Responsive برای موبایل و دسکتاپ

## محدودیت‌ها
این پروژه فرانت‌اند دمو است و درگاه پرداخت، API، پنل مدیریت یا بک‌اند ندارد. سفارش‌ها فقط در مرورگر کاربر و localStorage ذخیره می‌شوند. تصاویر از Unsplash و فونت از Google Fonts لود می‌شوند. پیش از انتشار تجاری، مجوز تصاویر و جایگزینی تصاویر نهایی را بررسی کنید.
